# Reference

This reference covers the current immunarch v1 API.

- Describe repertoires with [`airr_desc`](../man/airr_desc.md), [`airr_clonality`](../man/airr_clonality.md), and [`airr_diversity`](../man/airr_diversity.md).
- Compare repertoires with [`repsim`](../man/repsim.md) and find shared receptors with [`vdj_public`](../man/vdj_public.md).
- Track receptors across samples with [`vdj_track`](../man/vdj_track.md).
- Annotate receptors with [`annotate_clonality`](../man/annotate_clonality.md), [`annotate_with_database`](../man/annotate_with_database.md), and [`annotate_ig_clones`](../man/annotate_ig_clones.md).
- Calculate sequence distances with [`dist`](../man/dist.md) and cluster sequences with [`clust`](../man/clust.md).

The [retired v0 API page](../man/immunarch-v0-defunct.md) lists functions from the legacy API.
The internal helpers `im_common_args` and `register_immunarch_method` have been retired.

For tutorials, see the [single-cell guide](https://immunomind.github.io/docs/tutorials/single_cell/) and [migration guide](https://immunomind.github.io/docs/tutorials/migration/). The frozen [immunarch 0.9.1 archive](https://immunarch.com/archive/0.9.1/) covers the old release.
