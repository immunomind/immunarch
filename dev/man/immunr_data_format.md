

# Specification of the data format used by immunarch dataframes

## Description

<ul>
<li> &quot;Clones&quot; - number of barcodes (events, UMIs) or reads;

</li>
<li> &quot;Proportion&quot; - proportion of barcodes (events, UMIs) or reads;

</li>
<li> &quot;CDR3.nt&quot; - CDR3 nucleotide sequence;

</li>
<li> &quot;CDR3.aa&quot; - CDR3 amino acid sequence;

</li>
<li> &quot;V.name&quot; - names of aligned Variable gene segments;

</li>
<li> &quot;D.name&quot; - names of aligned Diversity gene segments or NA;

</li>
<li> &quot;J.name&quot; - names of aligned Joining gene segments;

</li>
<li> &quot;V.end&quot; - last positions of aligned V gene segments (1-based);

</li>
<li> &quot;D.start&quot; - positions of D'5 end of aligned D gene segments (1-based);

</li>
<li> &quot;D.end&quot; - positions of D'3 end of aligned D gene segments (1-based);

</li>
<li> &quot;J.start&quot; - first positions of aligned J gene segments (1-based);

</li>
<li> &quot;VJ.ins&quot; - number of inserted nucleotides (N-nucleotides) at V-J junction (-1 for receptors with VDJ recombination);

</li>
<li> &quot;VD.ins&quot; - number of inserted nucleotides (N-nucleotides) at V-D junction (-1 for receptors with VJ recombination);

</li>
<li> &quot;DJ.ins&quot; - number of inserted nucleotides (N-nucleotides) at D-J junction (-1 for receptors with VJ recombination);

</li>
<li> &quot;Sequence&quot; - full nucleotide sequence.

</li></ul>
