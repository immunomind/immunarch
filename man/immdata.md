

# Single chain immune repertoire dataset

## Description

A dataset with single chain TCR data for testing and examplatory
purposes.

## Usage

<pre><code class='language-R'>immdata
</code></pre>

## Format

A list of two elements. The first element ("data") is a list with data
frames with clonotype tables. The second element ("meta") is a metadata
table.

<dl>
<dt>data</dt><dd>List of immune repertoire data frames.
</dd>
<dt>meta</dt><dd>Metadata
</dd>
</dl>
