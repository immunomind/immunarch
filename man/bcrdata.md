

# BCR dataset

## Description

A dataset with BCR data for testing and examplatory purposes.

## Usage

<pre><code class='language-R'>bcrdata
</code></pre>

## Format

A list of two elements. The first element ("data") is a list of 1
element named "full_clones" that contains immune repertoire data frame.
The second element ("meta") is empty metadata table.

<dl>
<dt>data</dt><dd>List of immune repertoire data frames.
</dd>
<dt>meta</dt><dd>Metadata
</dd>
</dl>
