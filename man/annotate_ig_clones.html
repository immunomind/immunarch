    Build and annotate immunoglobulin clonal families¶

    Source code

    Description¶

    Build clonal families from B-cell receptors and assign them to receptors.

    Receptors are compared within a subject or repertoire. A heavy-chain edge requires a shared V/J union group, equal junction length, and normalized junction Hamming distance at or below heavy_threshold. Paired mode independently builds the corresponding light-chain graph and keeps receptors together only when they share both heavy- and light-chain families.

    Usage¶

    annotate_ig_clones(
  idata,
  heavy_threshold,
  light_threshold = NULL,
  mode = c("auto", "heavy", "paired"),
  by_scope = "<auto>",
  junction_col = "junction",
  v_col = "v_call",
  j_col = "j_call",
  heavy_locus = "IGH",
  clone_col = "clone_id"
)

    Arguments¶

    idata immundata::ImmunData. Paired or heavy-chain IG receptor data.
    heavy_threshold, light_threshold Numeric scalar or data frame. Normalized Hamming-distance threshold strictly between 0 and 1, or a complete table containing the by_scope column and a numeric threshold column. light_threshold defaults to heavy_threshold.
    mode Character scalar. Annotation strategy: "heavy" uses only the heavy chain, "paired" combines independently inferred heavy- and light-chain families, and "auto" selects paired mode for a paired IG receptor schema and heavy mode otherwise.
    by_scope Character scalar. Column that prevents clonal families from crossing biological subjects or repertoires. "<auto>" uses the first available subject-like column and otherwise the repertoire identifier.
    junction_col, v_col, j_col Character scalar. Columns containing the nucleotide junction, V call, and J call. V and J calls are grouped at gene level, allowing overlapping ambiguous assignments.
    heavy_locus Character scalar. Value identifying the heavy-chain locus. The default is "IGH"; all other loci declared by the receptor schema are treated as light chains in paired mode.
    clone_col Character scalar. Name of the combined clone annotation. The default is "clone_id".

    Details¶

    Connected components use single linkage: when A connects to B and B connects to C, all three receptors belong to one chain family even if A and C are farther apart than the threshold. Hamming distance compares only junctions of equal length, so it does not represent insertions or deletions.

    Junction nucleotides are converted to uppercase. Junctions containing characters other than A, C, G, and T cannot create edges and remain isolated.

    For grouping, V/J calls are split on commas or |, whitespace and allele suffixes are removed, and duplicate calls are ignored. Calls sharing both a V candidate and a J candidate are connected transitively within each scope and locus, before splitting by junction length or applying distance thresholds. Missing or empty gene calls cannot connect groups. Original calls and receptor IDs are preserved. The second example separately shows preprocessing when normalized calls should also define receptor identity.

    Value¶

    immundata::ImmunData. The original rows and columns plus clone_id (or the name supplied through clone_col), heavy_family_id, and light_family_id. Both chain rows of a paired receptor receive the same labels. In heavy mode, clone_id equals heavy_family_id and light_family_id is missing.

    Examples¶

    library("immunarch")




# Limit the number of threads used by the underlying DB for this example.
# Generally, you should NOT do this in your session.
db_exec("SET threads TO 1")

# Six chain observations representing three paired B-cell receptors.
ig_chains <- tibble::tribble(
  ~sample, ~cell, ~subject, ~locus, ~junction, ~v_call, ~j_call, ~umi,
  "S1", "c1", "P1", "IGH", "AAAA", "IGHV1", "IGHJ1", 10L,
  "S1", "c1", "P1", "IGK", "CCCC", "IGKV1", "IGKJ1", 8L,
  "S1", "c2", "P1", "IGH", "AAAT", "IGHV1", "IGHJ1", 10L,
  "S1", "c2", "P1", "IGK", "CCCT", "IGKV1", "IGKJ1", 8L,
  "S1", "c3", "P1", "IGH", "GGGG", "IGHV2", "IGHJ2", 10L,
  "S1", "c3", "P1", "IGL", "TTTT", "IGLV1", "IGLJ1", 8L
)
input_file <- tempfile(fileext = ".tsv")
output_folder <- tempfile("ig-clones-")
readr::write_tsv(ig_chains, input_file)

ig_schema <- make_receptor_schema(
  features = c("junction", "v_call", "j_call"),
  chains = c("IGH", "IGK|IGL")
)

idata <- read_repertoires(
  path = input_file,
  schema = ig_schema,
  barcode_col = "cell",
  locus_col = "locus",
  umi_col = "umi",
  repertoire_schema = "sample",
  rename_columns = NULL,
  output_folder = output_folder,
  verbose = FALSE
)

# c1 and c2 form one family; c3 remains separate.
annotated <- annotate_ig_clones(idata, heavy_threshold = 0.25)

annotated

    # Canonicalize ambiguous V/J calls lazily before receptors are constructed.
# For example, "IGHV2*01, IGHV1*02" becomes "IGHV1|IGHV2".
canonicalize_vj <- function(data, ...) {
  data |>
    dplyr::mutate(dplyr::across(
      c(v_call, j_call),
      ~ dd$array_to_string(
        dd$list_sort(dd$list_distinct(dd$string_split(
          dd$regexp_replace(
            dd$regexp_replace(.x, "\\*[0-9]+", "", "g"),
            "\\s+", "", "g"
          ),
          ","
        ))),
        "|"
      )
    ))
}

messy_chains <- ig_chains |>
  dplyr::mutate(
    v_call = dplyr::case_when(
      cell == "c2" & locus == "IGH" ~ " IGHV1*02, IGHV1*01 ",
      TRUE ~ paste0(v_call, "*01")
    ),
    j_call = paste0(j_call, "*01")
  )
messy_file <- tempfile(fileext = ".tsv")
canonical_folder <- tempfile("ig-clones-canonical-")
readr::write_tsv(messy_chains, messy_file)

canonical_idata <- read_repertoires(
  path = messy_file,
  schema = ig_schema,
  barcode_col = "cell",
  locus_col = "locus",
  umi_col = "umi",
  repertoire_schema = "sample",
  rename_columns = NULL,
  preprocess = list(canonicalize_vj = canonicalize_vj),
  output_folder = canonical_folder,
  verbose = FALSE
)

annotate_ig_clones(canonical_idata, heavy_threshold = 0.25)
